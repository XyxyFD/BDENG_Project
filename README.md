Alle Abgaben befinden sich im Ordner "Abgaben", alle projektbezogenen Dateien im Ordner "Project"
Project ist folgendermaßen aufgeteilt: Im Ordner Webscraping sind alle Python Scripts, welche die Daten von den Webseiten (Kayak, Momondo, Opodo) gescrapt haben.
Alle gescrapten html-Dateien wurden in den Ordner Html gespeichert.
In SEO-Analysis befinden sich alle Scripts und Daten, die wir benötigt haben, um zu analysieren, welche Webseiten am ehersten von Google vorgeschlagen werden
Im Ordner Flightprices_Analysis wurden die Daten von Opodo, Kayak und Momondo analysiert
Im Ordner DataExtraction sind die pythonfiles, welche die relevanten Daten, die analyisert wurden aus den HTML-Dateien genommen
Im Ordner APIs sind alle Dateien, die mit der Auswertung der REST-API Daten zu tun haben
Im Ordner Kafka_Spark ist der Code mit der Verarbeitung nochmal, nur das hier mit Spark und Kafka gearbeitet wurde.
